# Лучший день — демо сайта ювелирной мастерской

Демо для согласования с клиентом. Админки пока нет, данные лежат в коде, цены и камни условные.

## Что есть

- Главная: 3D-кольцо на первом экране, кнопки категорий, подборки, бриллианты, процесс изготовления, сервис, контакты.
- Каталог с фильтрами по категории, стилю, поиску и цене.
- Карточка кольца: калькулятор массы и цены (металл, цвет, размер, ширина, толщина, профиль, камни) и 3D-модель, которая меняется вместе с параметрами.
- Подбор бриллиантов: натуральные и выращенные, фильтры, карточка камня, «Вставить в кольцо».
- Индивидуальный заказ с вложением эскиза.
- Определение размера кольца по обхвату или диаметру.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000/testsite/

## Сборка

```bash
npm run build
```

Готовые статические файлы появятся в папке `out/`. Их нужно положить на сервер так, чтобы они открывались по адресу `/testsite/`.

## Где что лежит

- `src/lib/data.ts` — модели, металлы, тарифы, профили.
- `src/lib/calc.ts` — формулы калькулятора.
- `src/lib/diamonds.ts` — демо-сток бриллиантов.
- `src/components/Ring3D.tsx` — 3D-кольцо на three.js.
